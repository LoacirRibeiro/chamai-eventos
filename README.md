# 🚀 Chamaí - Organizador de Eventos Familiares

Sistema desenvolvido em Laravel para facilitar a organização de festas, churrascos e encontros.

### ✅ Funcionalidades:
- Criação de Eventos com links VIP únicos.
- Lista de convidados com confirmação de presença.
- Gestão de itens ("Quem leva o quê").
- Álbum de fotos compartilhado.
